# О смартапе
### Интеллектуальный ассистент по питанию, который всегда под рукой. Задайте цель — похудеть, набрать массу или питаться сбалансированно — и получите точный расчет КБЖУ. Ежедневно добавляйте продукты, а система считает калории и БЖУ, показывая остаток до нормы. Цветные прогресс-бары предупредят о переедании или недоборе. Встроенная рекомендательная система анализирует нехватку нутриентов и советует, что съесть: курицу для белка, рис для углеводов, овощи для лёгкости. Также можно искать рецепты по списку продуктов — просто введите, что есть в холодильнике, и получите пошаговые инструкции с КБЖУ на нужное количество порций. Простой путь к здоровому питанию без диетологов и сложных таблиц.
